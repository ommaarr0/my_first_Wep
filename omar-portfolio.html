أهلاً بك، أنا عمر محمد

مبرمج ومطور ويب من منيا القمح، الشرقية، مصر 🇪🇬

أعمل بجد للانضمام إلى كبرى الشركات التقنية وبناء مشاريع برمجية مبتكرة ومؤثرة.

مهاراتي البرمجية:

  • اللغات والأساسيات: HTML5, CSS3, JavaScript
  • التطوير: تصميم واجهات مستخدم تفاعلية، بناء تطبيقات ويب مصغرة
  • أدوات العمل: Git & GitHub

مشاريعي المميزة:

✂️ 🪨 📄 لعبة حجر ورقة مقص (Rock Paper Scissors)

تطبيق تفاعلي ممتع بلغات الويب لتمارين المنطق والتحكم في تفاعلات المستخدم (DOM Manipulation).

📝 قائمة المهام (To-Do List)

تطبيق عملي لإدارة المهام اليومية، يتيح إضافة وحذف المهام بمرونة لتنظيم الوقت وزيادة الإنتاجية.

💻 الموقع التفاعلي (الموقع الظريف)

مشروع تجريبي خاص قمت بتطويره لاختبار الأفكار البرمجية وتصميم واجهات عصرية وفريدة.
